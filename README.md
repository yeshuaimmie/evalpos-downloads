# EvalPOS downloads

The EvalPOS app for Windows, Mac and Android. Sign in with your EvalPOS email and password.

| Device | Download |
|---|---|
| Windows 10 / 11 | [EvalPOS-Setup.exe](https://github.com/yeshuaimmie/evalpos-downloads/releases/latest/download/EvalPOS-Setup.exe) |
| Mac (macOS 12 or newer) | [EvalPOS-macOS.zip](https://github.com/yeshuaimmie/evalpos-downloads/releases/latest/download/EvalPOS-macOS.zip) |
| Android | [EvalPOS-Android.apk](https://github.com/yeshuaimmie/evalpos-downloads/releases/latest/download/EvalPOS-Android.apk) |

- **Windows:** if "Windows protected your PC" appears, click **More info → Run anyway**.
- **Mac:** unzip, then the first time right-click **EvalPOS** → **Open** → **Open**.
- **Android:** allow "Install unknown apps" for your browser or file manager.

The first sign-in on a device needs internet; after that EvalPOS keeps selling offline.
More at [evalpos.tech](https://evalpos.tech).
